## Alphabetical glossary

*★ indicates an important function.*

| Function | Description | Topic(s) |
|---|---|---|
| <span id="abline"></span>`abline()` | Adds a straight line to an existing base-R plot. Here it adds the fitted regression line stored in a linear-model object. | Topic 5: Linear regression |
| <span id="aes"></span>**★** `aes()` | Defines how variables are mapped to visual properties in a ggplot, such as x position, y position, colour, or fill. | Topics 2, 3, 4, 5: ANOVA, 5: Linear regression, 6, 7 |
| <span id="anova"></span>`anova()` | Produces an analysis-of-variance table. It can test terms in one fitted model or compare nested models. | Topics 5: ANOVA, 6 |
| <span id="aov"></span>`aov()` | Fits an analysis-of-variance model. It is especially useful when the fitted model will be passed to `TukeyHSD()`. | Topic 5: ANOVA |
| <span id="arrange"></span>`arrange()` | Sorts the rows of a data frame by one or more variables. From **dplyr**. | Topic 4 |
| <span id="as-numeric"></span>`as.numeric()` | Converts suitable values, commonly character values or factor labels, to numeric values. | Topic 4 |
| <span id="binomial"></span>**★** `binomial()` | Specifies the binomial response distribution and logit link for `glm()`. | Topic 7 |
| <span id="boxplot-stats"></span>`boxplot.stats()` | Calculates the statistics used to draw a base-R boxplot, including its whiskers and possible outliers. | Topic 2 |
| <span id="c"></span>**★** `c()` | Combines individual values into a vector. It is used, for example, to set factor levels or specify plot limits. | Topics 1, 2, 5: ANOVA, 6 |
| <span id="cbind"></span>**★** `cbind()` | Combines vectors or objects as columns. In the grouped-binomial model, it supplies the numbers of successes and failures. | Topic 7 |
| <span id="chisq-test"></span>`chisq.test()` | Performs a chi-squared test of association between categorical variables in a contingency table. | Topic 3 |
| <span id="coef"></span>`coef()` | Extracts the fitted coefficient estimates from a model object. | Topic 6 |
| <span id="cor"></span>`cor()` | Calculates a correlation coefficient between two numeric variables. | Topic 3 |
| <span id="cor-test"></span>`cor.test()` | Tests a correlation and returns the estimated correlation, confidence interval, and p-value. | Topic 3 |
| <span id="coxph"></span>**★** `coxph()` | Fits a Cox proportional-hazards model to assess associations with time-to-event outcomes. From **survival**. | Assessment materials: Topic 8 |
| <span id="fn-data"></span>`data()` | Loads a built-in example dataset into the workspace. | Topic 1 |
| <span id="data-frame"></span>**★** `data.frame()` | Creates a data frame from one or more vectors. | Topics 6, 7 |
| <span id="dim"></span>`dim()` | Returns the dimensions of an object, normally its number of rows and columns for a data frame. | Topic 4 |
| <span id="dir"></span>`dir()` | Lists the files and folders in the current working directory. | Topic 1 |
| <span id="drop1"></span>**★** `drop1()` | Tests the effect of removing each eligible single term from a fitted model. With `test = "F"`, it provides F-tests for linear models; `test = "Chisq"` gives likelihood-ratio tests for GLMs. | Topics 6, 7 |
| <span id="drop-na"></span>**★** `drop_na()` | Removes rows with missing values in specified columns. From **tidyr**. | Topic 4 |
| <span id="exp"></span>`exp()` | Calculates the exponential of a number: \(e^x\). It reverses a natural-log transformation. | Topic 1 |
| <span id="facet-wrap"></span>`facet_wrap()` | Splits one ggplot into a panel for each level of a variable. | Topics 2, 3, 6 |
| <span id="factor"></span>**★** `factor()` | Converts a variable to a categorical factor, optionally setting the order and reference level of its categories. | Topics 2, 3, 5: ANOVA, 6 |
| <span id="filter"></span>**★** `filter()` | Keeps rows that meet one or more logical conditions. From **dplyr**. | Topics 4, 5: ANOVA |
| <span id="geom-abline"></span>`geom_abline()` | Adds one or more straight lines to a ggplot from supplied intercepts and slopes. | Topic 6 |
| <span id="geom-boxplot"></span>`geom_boxplot()` | Draws a boxplot in ggplot, showing the median, interquartile range, whiskers, and possible outliers. | Topics 2, 3, 5: ANOVA, 6 |
| <span id="geom-density"></span>`geom_density()` | Draws a smoothed estimate of a continuous variable's distribution. | Topics 2, 5: Linear regression, 6 |
| <span id="geom-histogram"></span>`geom_histogram()` | Draws a histogram by grouping a continuous variable into bins and counting observations in each bin. | Topics 2, 3, 6 |
| <span id="geom-line"></span>**★** `geom_line()` | Draws lines between observations or fitted values in their x-axis order. It is used for fitted probability curves. | Topic 7 |
| <span id="geom-point"></span>**★** `geom_point()` | Adds points to a ggplot, usually for a scatterplot. | Topics 2, 3, 4, 5: Linear regression, 6, 7 |
| <span id="geom-smooth"></span>`geom_smooth()` | Adds a fitted trend line and, by default, its confidence interval to a ggplot. `method = "lm"` fits a linear model. | Topics 2, 5: Linear regression, 6 |
| <span id="getwd"></span>`getwd()` | Returns the path of the current working directory. | Topic 1 |
| <span id="ggplot"></span>**★** `ggplot()` | Starts a ggplot figure by supplying data and, usually, aesthetic mappings. From **ggplot2**. | Topics 2, 3, 4, 5: ANOVA, 5: Linear regression, 6, 7 |
| <span id="glm"></span>**★** `glm()` | Fits a generalised linear model. Here it fits a binomial model for infection probabilities. | Topic 7 |
| <span id="grid-arrange"></span>`grid.arrange()` | Arranges several ggplot objects on one graphics page. From **gridExtra**. | Topic 3 |
| <span id="head"></span>`head()` | Displays the first few rows or elements of an object, providing a quick inspection of imported data. | Topics 1, 3, 4, 6 |
| <span id="install-packages"></span>`install.packages()` | Downloads and installs an R package from a package repository. This normally needs doing once per R installation. | Topic 3 |
| <span id="is-na"></span>`is.na()` | Identifies values that are missing (`NA`). | Topics 4, 5: ANOVA |
| <span id="labs"></span>**★** `labs()` | Sets ggplot labels such as axis labels, plot title, colour legend title, and fill legend title. | Topics 2, 5: ANOVA, 7 |
| <span id="library"></span>**★** `library()` | Loads an installed package for the current R session so its functions can be used by name. | Topics 3, 4, 7 |
| <span id="lm"></span>**★** `lm()` | Fits a linear model, including simple regression, multiple regression, ANOVA, and models with interactions. | Topics 5: ANOVA, 5: Linear regression, 6 |
| <span id="log"></span>**★** `log()` | Calculates logarithms, using the natural logarithm unless another base is supplied. | Topic 1 |
| <span id="log10"></span>`log10()` | Calculates base-10 logarithms. It is used here to transform biological measurements spanning a wide range. | Topic 5: Linear regression |
| <span id="ls"></span>`ls()` | Lists the objects currently stored in the R workspace. | Topic 1 |
| <span id="max"></span>`max()` | Returns the largest value in a numeric vector. | Topic 7 |
| <span id="mean"></span>**★** `mean()` | Calculates the arithmetic mean of numeric values. | Topics 3, 4 |
| <span id="min"></span>`min()` | Returns the smallest value in a numeric vector. | Topic 7 |
| <span id="mutate"></span>**★** `mutate()` | Creates new variables or changes existing variables in a data frame. From **dplyr**. | Topics 4, 5: ANOVA |
| <span id="names"></span>`names()` | Returns or sets the names of an object's elements or columns. Here it is introduced for checking variable names. | Topic 2 |
| <span id="nrow"></span>`nrow()` | Returns the number of rows in an object such as a data frame. | Topic 3 |
| <span id="par"></span>`par()` | Sets graphical parameters for base-R graphics. Here it creates a multi-panel layout for model diagnostic plots. | Topic 6 |
| <span id="pivot-longer"></span>`pivot_longer()` | Changes data from wide format to long format by turning several columns into values in a pair of new columns. From **tidyr**. | Topics 2, 4 |
| <span id="plot"></span>**★** `plot()` | Creates a base-R plot. Its behaviour depends on the data or model supplied; for an `lm` object it produces diagnostic plots. | Topics 1, 2, 5: ANOVA, 5: Linear regression, 6 |
| <span id="predict"></span>**★** `predict()` | Calculates fitted values or predictions from a fitted model for existing data or new values supplied in `newdata`. | Topics 6, 7 |
| <span id="qqline"></span>`qqline()` | Adds a reference line to a normal Q–Q plot, helping assess whether data are approximately normally distributed. | Topic 3 |
| <span id="qqnorm"></span>`qqnorm()` | Draws a normal Q–Q plot, comparing observed quantiles with those expected under a normal distribution. | Topic 3 |
| <span id="read-csv"></span>**★** `read.csv()` | Imports a comma-separated values file into a data frame. | Topics 2, 3, 5: ANOVA, 5: Linear regression, 6, 7 |
| <span id="read-table"></span>`read.table()` | Imports a delimited text file into a data frame. Its arguments control headers and separators. | Topics 1, 2, 3, 5: ANOVA, 6 |
| <span id="read-csv-underscore"></span>`read_csv()` | Imports a CSV file using **readr**. It is a tidyverse alternative to `read.csv()`. | Topics 4, 5: Linear regression |
| <span id="rename"></span>`rename()` | Changes column names in a data frame. From **dplyr**. | Topic 4 |
| <span id="scale-x-log10"></span>`scale_x_log10()` | Uses a base-10 logarithmic scale on the x-axis of a ggplot. | Topic 2 |
| <span id="scale-y-log10"></span>`scale_y_log10()` | Uses a base-10 logarithmic scale on the y-axis of a ggplot. | Topic 2 |
| <span id="sd"></span>`sd()` | Calculates the sample standard deviation, a measure of spread around the mean. | Topic 3 |
| <span id="select"></span>`select()` | Keeps, drops, or reorders columns in a data frame. From **dplyr**. | Topic 4 |
| <span id="seq"></span>`seq()` | Generates a sequence of values. | Topics 1, 7 |
| <span id="setwd"></span>`setwd()` | Changes R's working directory. R then looks there by default when reading and writing files. | Topic 1 |
| <span id="shapiro-test"></span>`shapiro.test()` | Performs the Shapiro–Wilk test for evidence against a normal distribution. | Topic 3 |
| <span id="sqrt"></span>`sqrt()` | Calculates square roots. | Topics 1, 3 |
| <span id="starts-with"></span>`starts_with()` | Selects column names beginning with specified text when used inside tidyverse selection functions. From **tidyselect**. | Topic 4 |
| <span id="step"></span>`step()` | Performs stepwise model selection, choosing changes according to AIC by default. | Topic 6 |
| <span id="str"></span>`str()` | Displays the internal structure of an object, including its type, dimensions, and the type of each variable in a data frame. | Topic 1 |
| <span id="subset"></span>`subset()` | Returns rows or columns that meet a condition. It is used here to create a dataset containing marsupials only. | Topic 5: Linear regression |
| <span id="summarise"></span>`summarise()` | Reduces each group, or the whole data frame, to summary values such as means and variances. From **dplyr**. | Topic 4 |
| <span id="summary"></span>**★** `summary()` | Produces an object-appropriate summary. For data frames it gives variable summaries; for models it reports estimates, uncertainty, and fit statistics. | Topics 1, 2, 3, 4, 5: ANOVA, 5: Linear regression, 6, 7 |
| <span id="surv"></span>**★** `Surv()` | Creates a survival-response object from follow-up time and an event indicator. From **survival**. | Assessment materials: Topic 8 |
| <span id="survfit"></span>**★** `survfit()` | Fits Kaplan–Meier survival curves or other survival estimates. From **survival**. | Assessment materials: Topic 8 |
| <span id="t-test"></span>`t.test()` | Performs a t-test to compare means or test a mean under the assumptions of the selected test. | Topic 3 |
| <span id="table"></span>`table()` | Counts combinations of values, producing a frequency or contingency table. | Topics 3, 4, 6 |
| <span id="theme-bw"></span>**★** `theme_bw()` | Applies ggplot2's black-and-white theme. | Topics 2, 5: ANOVA, 6, 7 |
| <span id="theme-classic"></span>`theme_classic()` | Applies ggplot2's classic theme with a plain background and axis lines. | Topics 4, 5: ANOVA, 5: Linear regression |
| <span id="tukeyhsd"></span>`TukeyHSD()` | Runs Tukey's honestly significant difference procedure for all pairwise comparisons after an ANOVA. | Topic 5: ANOVA |
| <span id="unname"></span>`unname()` | Removes names from a vector or other object while keeping its values. | Topic 6 |
| <span id="update"></span>**★** `update()` | Refits an existing model after changing its formula or another argument. | Topic 6 |
| <span id="var"></span>`var()` | Calculates the sample variance, a measure of numerical spread in squared units. | Topic 4 |
| <span id="view"></span>`View()` | Opens a spreadsheet-style data viewer in RStudio. | Topics 1, 3 |
| <span id="wilcox-test"></span>`wilcox.test()` | Performs a Wilcoxon rank-sum or signed-rank test, a non-parametric alternative to some t-tests. | Topic 3 |
| <span id="xlab"></span>**★** `xlab()` | Sets the x-axis label of a plot or ggplot. | Topics 2, 3, 4, 5: Linear regression, 6 |
| <span id="ylab"></span>**★** `ylab()` | Sets the y-axis label of a plot or ggplot. | Topics 2, 3, 4, 5: Linear regression, 6 |
